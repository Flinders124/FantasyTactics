# Media provenance
All character, scenery, UI, icon, score and sound assets come from this repository. Native captures use Godot 4.7.2. Headquarters and selection screens are real UI; the hero introduction uses the existing art-direction reference with its debug labels hidden; combat uses the existing developer fixture and accepted authoritative commands. Project audio is original CC0 (assets/audio/LICENSE.txt). No stock or generated game imagery, third-party score, voiceover, paid generation, upload or publishing.

GSAP 3.14.2 is stored in the local editing workspace; video typography uses Hyperframes bundled EB Garamond and Montserrat. Card snippets are crops of the actual selected Warden and Arcanist UI. The first edit used audio-energy data for a subtle brass divider; the final motion revision follows the measured 80 BPM beat grid and preserves the complete original music/SFX mix. Capture/build scripts and intermediate assets remain local and are excluded from the output/context commit.
